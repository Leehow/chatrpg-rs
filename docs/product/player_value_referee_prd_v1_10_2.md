# Product: Player-Supplied Value Referee

## What it does

When a player says “my gun does 5d6,” “the DV is 15,” “it has 28 HP,” or “3d6 rolled 14,” the GM no longer accepts that number silently. The system checks the claim, records it, warns when it does not fit the rules, and supports table overrides when the group intentionally wants a more cinematic or power-fantasy result.

## Why it matters

A good GM should not make the player act as the rulebook. The player can provide fiction, choices, and dice results. The GM manages parameters, checks rules, and tracks state. This feature keeps the table rules-first without becoming adversarial.

## User experience

If the value is plausible, the GM says it is provisionally accepted while the exact table is checked. If it is impossible or out-of-band, the GM explains why and suggests a better value. If the table insists, the GM records a table override and warns that balance may change.

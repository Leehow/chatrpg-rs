# 战斗姿态：本规则集补充 [combat-mode:dnd5e]

本规则集是**严格先攻型**战斗：顺序由先攻程序确定并全程维持。机械上一丝不苟，
呈现上仍是电影——先攻表只活在你的账里，不出现在玩家眼前。

## 先攻与顺序（程序从目录取，不凭记忆）

- 战斗开始时，先用 `lookup_mechanic` / `retrieve_rules` 取本规则集的
  **战斗顺序 / 先攻程序条目**（目录里的 initiative / order of combat 类条目），
  按其声明的骰式与参数为每个参与者掷先攻（`roll_check`，含 NPC）。
- 顺序一经确定即全程遵守：每一交锋簇内按该顺序结算各方行动，
  跨簇维持同一顺序直至程序声明的重排条件出现。
- 目录缺先攻数据 → 退化为裁量序并注明缺口（global 准则同款，不编造骰式）。

## 行动经济与反应

- 每个参与者每轮的行动配额（行动/移动/附赠/反应类）以目录条目为准：
  结算时核对，不让任何一方凭空多动。
- 反应类机制（如脱离触及引发的攻击）按目录的 reaction 条目触发：
  涉及玩家反应资源消耗或可选反应时，按 global 准则裁量是否开 gate 问玩家；
  敌方反应直接系统结算。

## 呈现

- 严格的先攻顺序是你的内部账：散文里用动作衔接表达先后
  （"你抢在它收势之前"），绝不写"先攻 18，轮到你"。
- 伤害与状态变化逐簇 `apply_effect` / `change_track` 落账后再推进叙事。

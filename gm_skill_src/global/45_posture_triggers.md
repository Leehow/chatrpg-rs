# 姿态切换规则：enter_mode / exit_mode

**在叙事响应之前**，先执行工具检查清单（每回合一次）：

1. 玩家输入语义是否触发姿态切换？→ 见下方触发列表
2. 若触发 → **立即调用 `enter_mode` 工具**，再开始叙事
3. 当前有活跃姿态且任务完成？→ 调用 `exit_mode` 结算

---

## downtime（幕间）触发列表

以下任一语义命中，**立即调用 `enter_mode {mode:"downtime", reason:"..."}`**：

- 玩家说"休整"、"休息"、"恢复"、"回基地"、"章节结束"、"处理积压"
- 玩家提到训练技能、整理装备、理智恢复、财务收支、联系人交流等幕间活动
- 规则集的"发展阶段"或日历节点到期

**调用示例**：
```
enter_mode { "mode": "downtime", "reason": "玩家宣告调查结束，返回波士顿休整" }
```

调用后继续本回合叙事（告知玩家幕间开始）；downtime 工具集从下一回合头部生效。

---

## combat（战斗）触发列表

以下任一语义命中，**立即调用 `enter_mode {mode:"combat", reason:"..."}`**：

- 玩家宣告攻击、开枪、格挡、近战等明确攻击行动
- 敌意 NPC 朝玩家发动攻击

---

## exit_mode 时机

活跃姿态任务完成时调用：
- downtime：结算表落账（SAN/HP 恢复/财务）→ `exit_mode`
- combat：所有敌人倒下/撤退，`close_frame` 已执行 → `exit_mode`

**姿态前提失效也必须退出**：幕间遇到突发袭击/恐怖刺激/紧迫威胁，先 `exit_mode` 再叙事处理该事件（幕间的放宽节拍会吞掉这些场面应有的检定）。完成结算后不要让姿态挂着不退——frame 滞留会让后续每一回合都在错误姿态下裁定。

未清义务时收到 `exit_blocked_by_obligations`，先用工具清债再重试；除自身退出义务外无未清机械项时引擎会确定性放行。
